Network Address Translation - механизм преобразования IP-адресов. Чаще всего NAT используется для того, чтобы устройства с частными (серыми) [[networks/IP|IP]] - адресами могли выходить в интернет через один публичный (белый) [[networks/IP|IP]] - адрес.
``` bash
# Пример запроса к сайту
Ноутбук
192.168.1.100:54321
        ↓
Роутер
89.208.15.42:40001
        ↓
Google
142.250.x.x:443

# Роутер запоминает соответствие
192.168.1.100:54321 - 89.208.15.42:40001

# Когда приходит ответ на 
89.208.15.42:40001

# Роутер понимает нужно вернуть пакет на 
192.168.1.100:54321
```

Бывает три типа:
1. Статический. Один окальный адресс равено одному глобальному. 

| Внутренний адрес | Внешний адрес |
| ---------------- | ------------- |
| 192.168.1.2      | 89.208.15.42  |
| 192.168.1.3      | 82.103.21.43  |
2. Динамический. Использует пул публичных адресов и назначает их по принципу "кто первый взял, того и тапки". 

| Внутренний адрес | Внешний адрес |
| ---------------- | ------------- |
| 192.168.1.2      | 89.208.15.42  |
| available        | 82.103.21.43  |
3. PAT. Переводит несколько локальных адресов, на один или несколько глобальных. Обычно pat пытаетс сохранить исходный порт источника.

| Внутренний адрес    | Внешний адрес      |
| ------------------- | ------------------ |
| 192.168.1.100:54321 | 89.208.15.42:54321 |
| 192.168.1.101:54322 | 89.208.15.42:54322 |
