Уникальный идентификатор сетевого интерфейса, длиной в 6 октетов (48 бит) - цифры от `0-9` и букы `a-f`. Он нужен для передачи кадров внутри локальной сети. Адрес делится на две основные части:
- Первые три октета - идентификатор производителя (OUI): Уникальный идентификатор организации, назначенный Институтом инженеров по электротехнике и радиоэлектронике (IEEE). 
- Последние три октета: Уникальный серийный номер, который производитель присваивает каждому отдельному устройству. 

Идентификатор сетевого интерфейса канального уровня, обычно длиной 48 бит (6 октетов). Записывается в шестнадцатеричном виде:
```text
00:1A:2B:3C:4D:5E
```

Используются цифры `0-9` и буквы `A-F`.

MAC-адрес нужен для передачи кадров внутри локальной сети. Коммутаторы используют MAC-адреса, чтобы понимать, через какой порт отправлять Ethernet-кадр.

MAC-адрес обычно состоит из двух частей:
- Первые 3 октета - OUI (`Organizationally Unique Identifier`) — идентификатор организации, назначаемый IEEE.
- Последние 3 октета - идентификатор конкретного сетевого интерфейса, назначаемый производителем.

Пример:
```text
00:1A:2B:3C:4D:5E
└───────┘ └───────┘
   OUI      Interface ID
```

> [!info] Важно
> MAC-адрес относится не ко всему устройству, а к **сетевому интерфейсу**. Поэтому ноутбук может иметь разные MAC-адреса для Ethernet и Wi-Fi.

## MAC и IP

MAC используется внутри локальной сети, а [[networks/IP|IP]] - для передачи пакетов между сетями.

Например, компьютер знает IP шлюза:
```text
192.168.1.1
```

Чтобы отправить ему Ethernet-кадр, компьютеру необходимо узнать его MAC-адрес. Для IPv4 это обычно делается через [[ARP]].
```text
192.168.1.1 → AA:BB:CC:DD:EE:FF
```

После этого Ethernet-кадр содержит:
```text
Source MAC:      MAC компьютера
Destination MAC: MAC шлюза
```

При прохождении через маршрутизатор MAC-адреса меняются, потому что они действуют только в пределах текущего канального сегмента. IP-адреса при обычной маршрутизации при этом остаются теми же.

## MAC не обязательно постоянный

Несмотря на то что производитель обычно назначает MAC-адрес интерфейсу, его можно программно изменить - `MAC spoofing`. Также современные ОС часто используют **MAC randomization**, например при подключении к Wi-Fi, чтобы усложнить отслеживание устройства. Поэтому утверждение «MAC - уникальный и неизменяемый адрес устройства» не совсем корректно.

## Специальный MAC

Broadcast MAC:
```text
FF:FF:FF:FF:FF:FF
```

Означает отправку кадра всем устройствам в данном broadcast-домене.
