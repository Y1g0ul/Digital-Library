Internet Protocol - сетевой протокол, отвечающий за **адресацию устройств и доставку пакетов между сетями**.

IP работает на сетевом уровне и позволяет маршрутизаторам передавать пакеты от одной сети к другой.

```text
Application
    ↓
TCP / UDP
    ↓
IP
    ↓
Ethernet / Wi-Fi
```

Основные версии:
```text
IPv4 → 32-битные адреса
IPv6 → 128-битные адреса
```

Подробно:

- [[IPv4]]
- [[IPv6]]


## Что делает IP

IP определяет:

```text
Кто отправитель?
Кто получатель?
Куда нужно передать пакет дальше?
```

В IP-пакете находятся адреса:

```text
Source IP
Destination IP
```

Например:

```text
Source IP:      192.168.1.10
Destination IP: 142.250.x.x
```

Маршрутизаторы смотрят на `Destination IP` и выбирают следующий маршрут.

## IP не гарантирует доставку

Сам IP не обеспечивает:

- подтверждение доставки;
    
- повторную передачу;
    
- правильный порядок;
    
- установку соединения.
    

```text
IP:
отправил пакет → дальше стараемся доставить
```

Надёжность при необходимости обеспечивает, например, [TCP](https://chatgpt.com/g/g-p-6a34bab6c94c8191a0ad3487c64dc054-seti/c/TCP).

## Важные поля

И IPv4, и IPv6 содержат:

- IP отправителя;
    
- IP получателя;
    
- информацию о версии протокола;
    
- ограничение количества переходов;
    
- указание, какой протокол находится внутри.
    

Например, в IPv4 поле `Protocol` может содержать:

```text
6  → TCP
17 → UDP
1  → ICMP
```

В IPv6 похожую задачу выполняет поле `Next Header`.

## TTL / Hop Limit

IP-пакет не может бесконечно ходить между маршрутизаторами.

В IPv4 используется:

```text
TTL — Time To Live
```

В IPv6:

```text
Hop Limit
```

Каждый маршрутизатор уменьшает значение на `1`.

```text
TTL 3
 ↓
TTL 2
 ↓
TTL 1
 ↓
TTL 0 → пакет уничтожается
```

Обычно при этом отправляется сообщение [ICMP](https://chatgpt.com/g/g-p-6a34bab6c94c8191a0ad3487c64dc054-seti/c/ICMP) `Time Exceeded`.
