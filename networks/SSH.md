SSH (Secure Shell) - сетевой протокол для безопасного удалённого подключения к другому компьютеру. SSH работает поверх [[TCP]]. Стандартный [[ports]] `22`.

Через SSH можно:
- удалённо войти на сервер;
- выполнять команды;
- копировать файлы;
- делать туннели;
- использовать Git по SSH;
- автоматизировать деплой.

## Как работает SSH
