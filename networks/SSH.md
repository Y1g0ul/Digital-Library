SSH (Secure Shell) - сетевой протокол для безопасного удалённого подключения к другому компьютеру. SSH работает поверх [[TCP]]. Стандартный [[ports]] `22`.

Через SSH можно:
- удалённо войти на сервер;
- выполнять команды;
- копировать файлы;
- делать туннели;
- использовать Git по SSH;
- автоматизировать деплой.

## Как работает SSH

### Транспортный слой

**`Задача:`** Превратить обычное [[TCP]] соединение в шифрованное.
1. Клиент открывает [[TCP]] соединение на порт 22.
2. Обе стороны отправляют друг другу строку с названием и версией своей программы (открытым текстом).
3. Стороны обмениваются списками того, что каждая умеет:
	- Какими способами готова обмениваться ключами.
	-  Какими шифрами шифровать. 
	-  Чем проверять целостность.
	Из этих списков ерется первый вариант который есть у обоих. 
4. Обе машины выполняют обмен ключами и получают общий секрет.
	Наружу уходят только публичные половины, а сам секрет ни разу не покидает машины. Из него обе стороны нарезают рабочие ключи. 

У каждого сервера есть постоянная пара ключей - ее называют хостовым ключом. Создается она один раз при установке. В конце обмена ключами сервер подписывает своим закрытым хостовым ключом отпечаток всего разговора который только что состоялся. Клиент провреяет эту подпись и если она сходится - свежий сессионный ключ намертво связан с личностью сервера. 

В отличии от браузера, гда за подтверждение подлинности ключа отвечают удостоверяющие центры, в [[linux/ssh|ssh]] идут на честный компромисс который называется доверием при первой встрече. При первом подлючении нам предлагают сверить короткий [[хеш]] открытого ключа сервера. Как только мы отвечаем `yes` ключ записывается в `~/.ssh/known_hosts` на машине. И дальше при каждом новом подключении клиент молча сверяет предьявленный ключ с сохраненным. 

В [[Linux]] SSH-сервер обычно реализуется через:

```text
OpenSSH
```
