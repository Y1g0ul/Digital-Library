## Цель 1: Охарактеризовать сервер.

Выясните, чем занимается сервер; каково его назначение (например, веб-сервер, сервер баз данных, сервер обработки данных и т. д.).
``` bash
sudo netstat -tlpn  # becoming obsolete
sudo ss -tlpn  # more modern (same flags!)
```
Конечно, мы можем использовать этот метод [[ps]] и для перечисления всех процессов:
``` bash
sudo ps auxf  # lots of flag options, play with them
```


## Цель 2: Определить уровень использования серверного оборудования.

Определите степень загрузки оборудования (процессора, оперативной памяти, диска, сети) и выявите, есть ли проблемы с какими-либо из этих ресурсов.
