Команда в [[Linux]] для удаления файлов и каталогов.

```bash
rm [ключи] <файл/каталог>
```

| Ключ              | Что делает                                                   |
| ----------------- | ------------------------------------------------------------ |
| `-r` / `-R`       | рекурсивно удалить каталог и всё внутри                      |
| `-f`              | удалить без подтверждения и игнорировать отсутствующие файлы |
| `-i`              | спрашивать подтверждение перед каждым удалением              |
| `-I`              | один раз спросить подтверждение при массовом удалении        |
| `-v`              | показывать удаляемые файлы                                   |
| `--preserve-root` | защита от рекурсивного удаления `/`                          |

Примеры:
```bash
rm file.txt
# удалить файл

rm file1 file2 file3
# удалить несколько файлов

rm *.log
# удалить все .log файлы в текущем каталоге

rm -r directory/
# удалить каталог со всем содержимым

rm -ri directory/
# рекурсивное удаление с подтверждением

rm -rf directory/
# принудительно удалить каталог без подтверждений

rm -v file.txt
# удалить файл и показать действие
```

`rm` удаляет имя файла из файловой системы. Если на inode больше не осталось ссылок и ни один процесс не держит файл открытым, его блоки освобождаются.

```text
имя файла
   ↓
inode
   ↓
данные на диске
```

Если файл удалён, но процесс продолжает держать его открытым, место может оставаться занятым до закрытия [[Файловые дескрипторы]].

```bash
lsof +L1
# найти удалённые, но всё ещё открытые файлы
```

> `rm` обычно не перемещает файлы в корзину. После удаления восстановление может быть сложным или невозможным, поэтому с `rm -rf` нужно быть особенно осторожным.
