Команда в [[Linux]] для просмотра запущенных [[процесс]]ов и информации о них.

```bash
ps [ключи]
```

По умолчанию показывает процессы текущего терминала.

|Ключ|Что делает|
|---|---|
|`aux`|показать почти все процессы с подробной информацией|
|`-ef`|показать все процессы в полном формате|
|`-f`|расширенный формат|
|`-F`|ещё более подробный формат|
|`-u <user>`|процессы конкретного пользователя|
|`-U <user>`|процессы по real UID|
|`-p <PID>`|показать конкретный PID|
|`--ppid <PID>`|показать дочерние процессы указанного процесса|
|`-C <name>`|найти процессы по имени команды|
|`-q <PID>`|быстрый выбор по PID|
|`-o`|выбрать выводимые поля|
|`--sort`|сортировать по указанному полю|
|`--forest`|показать дерево процессов|
|`-H`|показать процессы в иерархии|
|`-L`|показать потоки процесса|
|`-T`|показать потоки текущего терминала|
|`-e`|показать все процессы|
|`-a`|показать процессы других пользователей с терминалом|
|`-x`|включить процессы без терминала|
|`-N`|показать процессы, не попавшие под условие|
|`--no-headers`|убрать заголовки|
|`ww`|не обрезать длинные команды|

Основные поля:

|Поле|Что показывает|
|---|---|
|`PID`|идентификатор процесса|
|`PPID`|PID родительского процесса|
|`USER`|пользователь процесса|
|`%CPU`|использование CPU|
|`%MEM`|использование RAM|
|`VSZ`|виртуальная память|
|`RSS`|реально используемая RAM|
|`STAT`|состояние процесса|
|`TTY`|терминал процесса|
|`START`|время запуска|
|`TIME`|использованное CPU-время|
|`COMMAND`|команда процесса|

Основные состояния `STAT`:

|Состояние|Значение|
|---|---|
|`R`|выполняется или готов к выполнению|
|`S`|спит, ожидая событие|
|`D`|непрерываемое ожидание, обычно I/O|
|`T`|остановлен|
|`Z`|zombie-процесс|

Примеры:

```bash
ps aux
# показать почти все процессы

ps -ef
# показать все процессы с PID и PPID

ps auxf
# показать дерево процессов

ps -p 1234 -f
# подробная информация о PID 1234

ps --ppid 1234
# показать дочерние процессы PID 1234

ps -C nginx
# найти процессы nginx

ps -L -p 1234
# показать потоки процесса

ps -o pid,ppid,user,stat,%cpu,%mem,cmd
# вывести только выбранные поля

ps aux --sort=-%cpu | head
# процессы с наибольшей загрузкой CPU

ps aux --sort=-%mem | head
# процессы с наибольшим использованием памяти

ps auxww
# показать полные команды без обрезки

ps -eo pid,ppid,stat,cmd --forest
# вывести дерево всех процессов
```

Полезно помнить:

```text
ps aux
→ удобный подробный снимок процессов

ps -ef
→ удобен для PID/PPID и иерархии

top / htop
→ процессы в реальном времени
```
