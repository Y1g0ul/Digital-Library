Команда в [[Linux]] для отображения информации о пользователях, вошедших в систему, и их текущей активности.

``` bash
w [ключ]
```

| Ключ | Что делает |
|------|------------|
| `-h` | не выводить заголовок |
| `-s` | краткий вывод |
| `-f` | не показывать поле `FROM` |
| `-i` | показывать IP-адрес вместо имени хоста |

Основные поля вывода:

| Поле | Что показывает |
|------|----------------|
| `USER` | имя пользователя |
| `TTY` | терминал пользователя |
| `FROM` | IP-адрес или имя хоста |
| `LOGIN@` | время входа |
| `IDLE` | время бездействия |
| `JCPU` | время CPU всех процессов терминала |
| `PCPU` | время CPU текущего процесса |
| `WHAT` | выполняемая команда |

Примеры:
``` bash
w              # показать всех пользователей
w -h           # без заголовка
w -s           # краткий вывод
w -i           # показать IP-адреса
```

Команда полезна для:
- просмотра пользователей, работающих в системе;
- определения, кто подключён по SSH;
- просмотра времени входа и простоя;
- определения выполняемой пользователем команды.
