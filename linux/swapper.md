`PID 0` - специальный процесс ядра [[Linux]], который не является обычным пользовательским процессом. Он создаётся ещё во время загрузки ядра и связан с **idle-задачей / scheduler**.

```text
PID 0
↓
ядро Linux
↓
idle / scheduler
```

Когда конкретному CPU нечего выполнять, он запускает свою idle-задачу.

`PID 0` нельзя увидеть как обычный процесс через:
```bash
ps aux
```

Из него во время загрузки создаётся первый обычный процесс:
```text
PID 0
 ↓
PID 1 → systemd / init
```

Главное:
```text
PID 0 → специальная задача ядра
PID 1 → первый пользовательский процесс
```
