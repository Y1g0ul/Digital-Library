Команда в [[Linux]] для перемещения и переименования файлов и каталогов.

```bash
mv [ключи] <источник> <назначение>
```

|Ключ|Что делает|
|---|---|
|`-i`|спрашивать перед перезаписью|
|`-f`|перезаписывать без подтверждения|
|`-n`|не перезаписывать существующие файлы|
|`-v`|подробный вывод|
|`-b`|создавать резервную копию перезаписываемого файла|

Примеры:

```bash
mv file.txt /tmp/
# переместить файл

mv file.txt newname.txt
# переименовать файл

mv dir1 /tmp/
# переместить каталог

mv *.log /var/log/archive/
# переместить все .log файлы

mv -i file.txt /tmp/
# спросить перед перезаписью

mv -n file.txt /tmp/
# не перезаписывать существующий файл

mv -v file.txt /tmp/
# показать, что было перемещено

mv file1 file2 directory/
# переместить несколько файлов в каталог
```

Если источник и назначение находятся в одной файловой системе, `mv` обычно просто меняет запись о расположении файла, не копируя его данные.

Если перемещение идёт между разными файловыми системами, `mv` фактически копирует файл, а затем удаляет исходный.
