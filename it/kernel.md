**Linux kernel** - ядро операционной системы [[Linux]]. Это главный компонент системы, который работает между программами и оборудованием.

Основные задачи ядра:
- управление [[процесс]]ами;
- управление оперативной памятью;
- работа с устройствами через драйверы;
- работа с файловыми системами;
- управление сетью;
- контроль прав доступа и изоляции;
- предоставление программам системных вызовов.

Упрощённо:
```text
Программы
   ↓
system calls
   ↓
Linux kernel
   ↓
Оборудование
```

Программы обычно не обращаются к оборудованию напрямую - они запрашивают нужные действия у ядра. Linux kernel является **монолитным ядром с поддержкой модулей**: большая часть основных подсистем работает внутри ядра, а дополнительную функциональность, например драйверы, можно подключать в виде модулей ядра.
