Команда для запуска [[container]] в [[docker]].
``` shell
docker start [OPTIONS] CONTAINER [CONTAINER...]
```
- `-i` - для подключения контейнера к терминалу.
- `-a` — подключиться к `STDOUT` и `STDERR` контейнера и видеть его вывод
