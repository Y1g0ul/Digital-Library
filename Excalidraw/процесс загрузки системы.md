## Text Elements
BIOS / UEFI ^dwoJBW22

Самое первое, что стартует при включении ПК.
- Инициализирует железо (CPU, RAM, диски)
- Выполняет POST POST (Power-On Self-Test) в 
системе UEFI — это этап первичного аппаратного 
самотестирования, который компьютер выполняет сразу 
после включения питания.
- Ищет устройство для загрузки
- Передаёт управление загрузчику

Для BIOS загрузчик может начинаться с кода в MBR.

Для UEFI запускается .efi-файл из EFI System Partition:
/boot/efi/EFI/... ^i51YMcaY

GRUB ^7cuUlBsi

- Показывает меню выбора ОС
- Загружает в RAM:
    1. Linux kernel
    2. initramfs
- Передаёт управление ядру ^2KUhYNfI

Linux Kernel ^H3SHVT3z

Ядро:
- Инициализирует CPU, память, драйверы
- Настраивает управление памятью
- Обнаруживает оборудование 
- Загружает необходимые драйверы
- Запускает временную корневую среду из initramfs  ^bzfiSfwh

initramfs ^MELiEdVs

Минимальная временная Linux-среда, необходимая для запуска 
основной системы. Она может:
- Загрузить необходимые драйверы;
- Активировать LVM;
- открыть LUKS;
- собрать RAID;
- найти настоящий корневой раздел / и смонтировать его.

После этого происходит switch_root и управление передаётся 
системе на настоящем /. ^bB37uKCH

systemd ^dFcK835I

Ядро запускает первый userspace-процесс /sbin/init.
В большинстве современных Linux: /sbin/init -> systemd
systemd становится PID 1 и начинает:
- Монтировать файловые системы;
- Поднимать сеть;
- Запускать службы;
- Запускать нужный target;
- Запускать getty или display manager. ^kcLWGQSX

Linux Kernel ^qFuUqWkX

Ядро:
- инициализирует CPU, память, драйверы
- монтирует временную FS (initramfs)
- подготавливает систему к userspace ^e2bsXOAn

Запуск init ^Bl2e3aeb

Ядро запускает первый процесс.
В современных системах это systemd ^dBVdN2yy

Пользовательская среда ^7Hy6TLVR

systemd:
- запускает сервисы
- поднимает сеть
- монтирует диски
- запускает:
    - SSH
    - GUI (если есть)
    - getty / login ^SJoShBPi
