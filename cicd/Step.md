Отдельное действие внутри [[Job]]. Step выполняет одну конкретную операцию: запускает команду, использует Action или выполняет скрипт. Разбивает [[Job]] на последовательность простых действий:
- Получить код из репозитория.
- Установить зависимости.
- Запустить тесты.
- Собрать [[docker]]-образ.
- Загрузить артефакты.

Build Job
├── Checkout repository
├── Install dependencies
├── Build application
└── Upload artifact
