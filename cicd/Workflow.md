Описание процесса автоматизации, который выполняется после наступления [[Event]], сценарий (план) выполнения Pipeline.

Workflow отвечает на вопрос:
> *"Что нужно сделать после события?"*

Содержит:
- Jobs
- условия запуска ([[Event]])
- переменные
- разрешения
- другие настройки

Event: `push`
↓
Workflow:
- Получить код из репозитория.
- Установить зависимости.
- Запустить тесты.
- Собрать Docker-образ.
- Отправить образ в Registry.

GitHub Actions:
`.github/workflows/*.yml`

GitLab CI:
`.gitlab-ci.yml`

## Запомнить

Workflow — это **сценарий (план)** выполнения Pipeline.

Он описывает:
- **когда** запускаться (Event);
- **что** выполнять (Jobs);
- **в каком порядке** выполнять задачи
