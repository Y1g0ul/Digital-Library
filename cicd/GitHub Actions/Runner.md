Cервер, виртуальная машина или контейнер, который выполняет [[cicd/GitHub Actions/Job]]s из [[cicd/GitHub Actions/Pipeline]]. Runner получает [[cicd/GitHub Actions/Job]], запускает все его [[Step]]s и сообщает результат системе CI/CD.
- Hosted Runner - предоставляется GitHub/GitLab.
- Self-hosted Runner - разворачивается пользователем на собственном сервере.
